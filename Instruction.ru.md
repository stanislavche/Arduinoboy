## 1. Пинаут Teensy 2.0 (Teensyduino)

Используемые пины отмечены ★:

```
              ┌──────[USB]──────┐
         GND ─┤                 ├─ VCC
★ SCK  PB0 0 ─┤ → GB Link Pin 5 ├─ 21 PF0
★  SI  PB1 1 ─┤ → GB Link Pin 3 ├─ 20 PF1
★  SO  PB2 2 ─┤ ← GB Link Pin 2 ├─ 19 PF4
       PB3 3 ─┤                 ├─ 18 PF5
       PB7 4 ─┤                 ├─ 17 PF6
       PD0 5 ─┤  ATmega32U4     ├─ 16 PF7
       PD1 6 ─┤                 ├─ 15 PB6
★ MIDI PD2 7 ─┤ ← Serial1 RX   ├─ 14 PB5
       PD3 8 ─┤                 ├─ 13 PB4
       PC6 9 ─┤                 ├─ 12 PD7
      PC7 10 ─┤                 ├─★11 PD6 ← ONBOARD LED
              └─────────────────┘
                       ▲
               VIN ← GB Link Pin 1 (VCC +5V)
               GND ← GB Link Pin 6 (GND)
```

| Пин Teensy | Порт | Назначение              | Куда              |
|------------|------|-------------------------|-------------------|
| **Pin 0**  | PB0  | SCK — такт              | → GB Link Pin 5   |
| **Pin 1**  | PB1  | SI — данные в GB        | → GB Link Pin 3   |
| **Pin 2**  | PB2  | SO — данные из GB       | ← GB Link Pin 2   |
| **Pin 7**  | PD2  | MIDI IN (Serial1 RX)    | ← 6N138 выход     |
| **Pin 11** | PD6  | Onboard LED             | —                 |
| **VIN**    | —    | Питание 5V              | ← GB Link Pin 1   |
| **GND**    | —    | Земля                   | ← GB Link Pin 6   |

## 2. DMG Link Port → Teensy 2.0

### DMG EXT разъём — нумерация пинов

```
  ЛИЦЕВАЯ СТОРОНА (вид снаружи, как вставляется кабель):

        левый край GB              правый край GB
        ┌───────────────────────────────────────┐
        │   2 (SO)    4 (NC)    6 (GND)         │  ← верхний ряд
        │   ────────────────────────────        │
        │   1 (VCC)   3 (SI)    5 (SCK)         │  ← нижний ряд
        └─────────────────────────────────── ╗  │
                                             ╚══╝  ← отверстие порта
```

```
  СТОРОНА ПАЙКИ (solder side) — как видно изнутри GB при пайке:

        левый край GB              правый край GB
        ┌───────────────────────────────────────┐
        │   1 (VCC)   3 (SI)    5 (SCK)         │  ← верхний ряд ★ ПАЯТЬ СЮДА
        │   ────────────────────────────        │     (разделитель/перегородка)
        │   2 (SO)    4 (NC)    6 (GND)         │  ← нижний ряд  ★ ПАЯТЬ СЮДА
        └─────────────────────────────────── ╗  │
                                             ╚══╝  ← отверстие порта (низ GB)
```

Измеренные напряжения на падах (GB включён, программа в простое):

```
  SOLDER SIDE:
  ┌────────────────────────────────────────────────────┐
  │  [1 / VCC]   [3 / SI]    [5 / SCK]                │
  │   ~4.85 V    ~5.09 V     ~5.09 V                  │  ← верхний ряд
  │  ─────────────────────────────────                 │
  │  [2 / SO]    [4 / NC]    [6 / GND]                │
  │    0 V         0 V         0 V                    │  ← нижний ряд
  └──────────────────────────────────── отверстие ────┘
```

> VCC ~4.85V — напряжение батареи (норма).  
> SI и SCK ~5.09V — pull-up к VCC (5.09V на шине GB), idle-high.  
> SO = 0V — idle-low, данные только во время передачи.  
> ⚠️ Пины **3 (SI) и 5 (SCK)** соседние в верхнем ряду — не допускать замыкания при пайке!

**Таблица подключения (solder side, слева направо):**

| Позиция (solder side) | Пин DMG | Сигнал      | Teensy         | Направление          |
|-----------------------|---------|-------------|----------------|----------------------|
| верхний левый         | **1**   | **VCC +5V** | **VIN**        | GB → Teensy (питание)|
| верхний центр         | **3**   | **SI**      | **Pin 1** (PB1)| Teensy → GB (данные) |
| верхний правый        | **5**   | **SCK**     | **Pin 0** (PB0)| Teensy → GB (такт)   |
| нижний левый          | **2**   | **SO**      | **Pin 2** (PB2)| GB → Teensy (данные) |
| нижний центр          | **4**   | NC          | —              | не подключать        |
| нижний правый         | **6**   | **GND**     | **GND**        | GB → Teensy (земля)  |

| Link Pin | Сигнал     | Направление          | Teensy 2.0     | Порт        |
|----------|------------|----------------------|----------------|-------------|
| 1        | VCC (+5V)  | GB → Teensy (питание)| **VIN**        | —           |
| 2        | SO         | GB → Teensy (данные) | **Pin 2** (PB2)| PORTB бит 2 |
| 3        | SI         | Teensy → GB (данные) | **Pin 1** (PB1)| PORTB бит 1 |
| 4        | SD/NC      | не используется      | —              | —           |
| 5        | SCK        | Teensy → GB (такт)   | **Pin 0** (PB0)| PORTB бит 0 |
| 6        | GND        | Общая земля          | **GND**        | —           |

> Пины 0, 1, 2 находятся на одном регистре PORTB — это позволяет атомарно
> менять тактовый и сигнальные пины одной инструкцией (`PORTB = ...`).

## 3. MIDI IN: 3.5mm TRS Type A (M8) → 6N138 → Teensy

### M8 TRS Type A MIDI Out

```
  TRS Jack
  ─ Tip    = DIN-5 Pin 5 (ток, сток/транзистор M8)
  ─ Ring   = DIN-5 Pin 4 (источник +V через 220Ω внутри M8)
  ─ Sleeve = GND
```

### Схема с оптоизолятором 6N138

```
  TRS JACK          6N138 (DIP-8)                    TEENSY 2.0
  ─────────        ┌──────────────┐                  ────────────
                   │ 1 NC         │  не подключать
  Ring (+) ──220Ω──┤ 2 A (Anode)  │
  Tip  (−) ────────┤ 3 C (Cathode)│
  1N5819: катод    │ 4 NC         │  не подключать
  (белая)→Pin2,    │ 5 GND        ├──────────────────── GND
  анод→Pin3        │ 6 V0 (Out)   ├──┬─────────────────── Pin 7 (RX)
                   │ 7 NC         │  │   не подключать
  VCC (+5V) ───────┤ 8 VCC   ←─270Ω──┘  (pull-up между Pin6 и Pin8/VCC)
                   └──────────────┘
  Pin 8 → VCC  напрямую (без резистора)
  270Ω  → между Pin 6 и VCC (pull-up, как на схеме PC900)
  Pin 5 → GND  напрямую (резистор на землю НЕ нужен)

  Sleeve ────────────────────────────────────────────── GND
```

> **Итого нужно всего 2 резистора:** 220Ω (на входе) + 270Ω (pull-up выхода)

### Компоненты MIDI-схемы

| Компонент    | Номинал  | Назначение                              |
|--------------|----------|-----------------------------------------|
| R1           | 220 Ω    | Токоограничительный резистор входа LED  |
| R2           | 270 Ω    | Pull-up на выходе коллектора (как PC900)|
| D1 (1N5819)  | —        | Защита от обратной полярности           |
| IC1 (6N138)  | —        | Оптоизолятор                            |

## 6. Режимы и переключение (справка)

| Режим      | Program Change | Поведение LED при включении   | M8 канал                  |
|------------|----------------|-------------------------------|---------------------------|
| mGB        | PC 0           | **1 бликание**                | MIDI Out → mGB ch 1-5     |
| LSDJ Slave | PC 1           | **2 бликания**                | Clock/Transport → GB LSDJ |
| Nanoloop   | PC 2           | **3 бликания**                | Clock → GB Nanoloop       |

**Переключение режимов:** MIDI Program Change на **канале 16** (USB или TRS jack).
